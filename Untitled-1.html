How to change to the custom(community) server:

( Vilent normal) if you have standard installation path then go to C:/users/me/documents/vilent/vilent/authip.txt and paste your ip ex: 127.0.0.1:5000

( Vilent normal) if you have standard installation path then go to C:/users/me/documents/vilent/vilent/talkip.txt and paste your ip ex: 127.0.0.1:3000 to change the chatroom

For vilent mini:

( Vilent mini) if you have standard installation path then go to C:/users/me/documents/vilentMini/vilent/authip.txt and paste your ip ex: 127.0.0.1:5000

( Vilent mini) if you have standard installation path then go to C:/users/me/documents/vilentMini/vilent/talkip.txt and paste your ip ex: 127.0.0.1:3000 to change the chatroom

You can change the chatroom even if you still want to login on the default server
