ABOUT

A simpler way to launch Minecraft

JanekLauncher is a custom Minecraft launcher designed to make switching between Minecraft versions, modpacks and accounts simple.

Choose a Minecraft version, select your account and press PLAY. If Minecraft is not installed, JanekLauncher can download the required files automatically.

Custom JanekLauncher packages can include their own Minecraft version, mod loader configuration and mods.

FEATURES

What it can do

Minecraft versions

  • Launch Minecraft releases
  • Launch old beta versions
  • Launch old alpha versions
  • Automatic Minecraft installation

Modpack support

  • Import JanekLauncher modpack ZIP files
  • Separate game folders for each pack
  • Automatic mod copying
  • Custom replacement client JAR support

Mod loaders

  • Forge
  • NeoForge
  • Fabric
  • Quilt

Accounts and Java

  • Microsoft account login
  • Offline profile support
  • Select your own Java installation
  • Saved Microsoft login
