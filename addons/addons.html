jeasydata:

how to import:

download the file using
pip install Jeasydata==0.1.3


After that just use
import jeasydata

Functions:

encode. Encode function adds a byte to the file so other reading functions won't read it
file = "file.jbk"
jeasydata.encode(file)
decode. Decode function deletes the first byte from the file
file = "file.jbk"
jeasydata.decode(file)
read. Read function reads the file provided and returns dataout which is a list
file = "file.jbk"
out = jeasydata.read(file)
print(out)
Result: ['sigma', '@tuff boy', 'sigma2', '@tuff boy2']
target. Target function is used when you know the first value (target)
file = "file.jbk"
out = jeasydata.target("sigma", file)
print(out)
Result: ['tuff boy']
readAll. used when you don't know the target. returns targets and data
file = "file.jbk"
out = jeasydata.readAll(file)
print(out)
Result: ['sigma', 'sigma2'] ['tuff boy', 'tuff boy2']
readAllTargets. returns targets, data, and a dict
file = "file.jbk"
out = jeasydata.readAllTargets(file)
print(out)
Result: ['sigma', 'sigma2'] ['tuff boy', 'tuff boy2']
{'sigma': ['tuff boy'], 'sigma2': ['tuff boy2']}
save. saves files. Val1 is the target and Val2 is the data
file = "file.jbk"
val1 = "apple"
val2 = "mango"
jeasydata.save(val1, val2, file)
Result: saved file
delete. deletes the targeted line. Val1 is the target
file = "file.jbk"
val1 = "apple"
jeasydata.delete(val1, file)
Result: deleted apple and its value in the file

Usage:

How to get a clean string? The addon outputs lists so you need to "delist" it:
import jeasydata as j
file = "test.jbk"
dataout = j.read(file)
out = j.target(dataout[0], file)
print(out[0])
Remember that target will always be 0,3,5,7,9 and more.
